# 🎯 Desafio Criativo: Prototipação do Educador Financeiro Inteligente

## 🚀 Prompt Estruturado Final

Atue como um especialista em educação financeira digital.
Crie a proposta de um Educador Financeiro Inteligente para desenvolvedores junior e iniciantes da área de TI.

O sistema deve ajudar o usuário a organizar o orçamento mensal, reservar dinheiro para estudos/certificações e evitar compras por impulso.

As principais funcionalidades devem incluir:
- Calculadora de meta financeira para compra de equipamentos de trabalho
- Simulador de gastos mensais categorizados (estudos, lazer, contas fixas)
- Dicas inteligentes baseadas no fluxo de caixa atual do usuário

A comunicação deve ser direta, amigável e com toque de cultura tech.

As respostas devem seguir o formato de tópicos objetivos com exemplos de aplicação no código/projeto.

Evite linguagem bancária formal demais e teorias complexas de investimentos de alto risco.

Ao final, apresente sugestões criativas para transformar essa ideia em um projeto frontend interativo.
